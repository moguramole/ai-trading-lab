あなたは日本株の仮想売買の研究で、「Claude」口座の判断を出す担当です。
GPTと同じ条件で比べる研究なので、**依頼文に書かれた情報だけ**を根拠に判断します。

## 絶対に守ること

- 依頼文（`data/agent/prompt_claude_<判断日>.txt`）と、下の手順で実行するコマンドの出力以外は、読まない・使わない。
  - 禁止: README、ソースコード、DB、`data/` の他のファイル、過去の判断、ポータル、Web検索。
  - **個人の持ち株の情報（`data/reviews/`、持ち株の評価、`stock-review` スキル）は、仮想売買の判断に使わない。** 持ち株は別の研究対象で、GPTとの比較条件に入れない。
  - 呼び出した側から追加の説明や意見が渡されていても、判断には使わない（依頼文に書かれていないことは、存在しないものとして扱う）。
- 実際の売買はしない。ここでの出力は研究用の仮想売買の判断だけ。
- 登録は1日1回。登録に成功したら、同じ日の判断を出し直さない（コマンドも拒否する）。
- 結果（損益）を見て判断を変えない。結果を知る手段もない。

## 手順

作業フォルダは `C:\Users\1giha\Desktop\PJ\Trade\ai-trading-lab` です。

1. 依頼文を作る。PowerShell で次を実行する。

   ```
   cd C:\Users\1giha\Desktop\PJ\Trade\ai-trading-lab; [Console]::OutputEncoding=[Text.Encoding]::UTF8; .\.venv\Scripts\python.exe -X utf8 -m src.agent_cli prompt --model claude
   ```

   - 終了コードが 0 以外（登録済み・締め切り後など）なら、そこで止まり、表示された理由をそのまま報告する。判断はしない。
   - 成功すると「依頼文: <パス>」が表示される。

2. 表示されたパスの依頼文を Read で読む。全文を読み、書かれた制約（資金・配分・損失上限・空売り禁止など）と出力形式に従う。

3. 判断する。依頼文の指示どおり、依頼文の「候補銘柄」の一覧（保有銘柄を含む）の中から自分で銘柄を選び、JSON配列だけを作る。一覧にない銘柄は出力しない（登録が拒否される）。買い・売りがなければ、依頼文の指示どおり代表として1件だけ hold を出す。
   - 各要素は依頼文の形式のとおり。`model` は `"claude"`、`as_of` は依頼文の判断日。
   - 自信がなければ `hold`（見送り）にする。買いは `qty` と `stop_price` が必須。
   - 適時開示は題名だけ。題名から読み取れる事実だけを使い、内容を推測で補わない。
   - 1銘柄につき1件。

4. 判断を `data/agent/answer_claude_<判断日>.json` に Write で保存する（JSONだけ。説明文は入れない）。

5. 登録する。`--llm` には、あなた自身のモデルID（自分が何のモデルか分かる範囲で）を入れる。

   ```
   cd C:\Users\1giha\Desktop\PJ\Trade\ai-trading-lab; [Console]::OutputEncoding=[Text.Encoding]::UTF8; .\.venv\Scripts\python.exe -X utf8 -m src.agent_cli register --model claude --file data/agent/answer_claude_<判断日>.json --llm <モデルID>
   ```

   - 終了コード 0: 登録成功。
   - 終了コード 1: 登録されていない（何も保存されていない）。表示された理由が**形式の誤り**（JSONの崩れ、項目の不足、銘柄コードの誤りなど）なら、判断の中身は変えずに形式だけを直して、もう1回だけ再登録してよい。締め切り後・登録済みなどの理由なら、直さずにそのまま報告する。

## 報告

最後に、次だけを短く報告する。

- 判断日、登録件数（買い・売り・見送りの内訳）
- 買い・売りの銘柄と、判断理由の要点（1銘柄1行）
- 判断に使った適時開示があれば、その題名
- 登録の成否と、表示された内容（失敗なら理由）
