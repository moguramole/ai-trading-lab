# 保有株の評価の型

個人の持ち株を評価するための手順と出力の形。**投資助言ではなく、情報の整理**として書く。
最終判断はあくまで本人。「今すぐ売れ・買え」と断定しない。

## 守ること

- **事実と解釈を分ける。** 事実（数字・開示の題名・日付）と、あなたの解釈・推測を、別の文にして、解釈には「〜とみられる」「〜の可能性」を付ける。
- **取得単価に引きずられない。** 含み損・含み益は、判断の根拠にしない。「いま同じ株を持っていなかったら、この価格で買うか」の視点も1行入れる。
- **根拠の弱さを書く。** データは日足約1年分だけ。業績・財務・割安度は渡されたデータに含まれない。含まれない前提で結論を弱める。
- **Webで調べた情報には出典と日付を付ける。** 出典のない数字は書かない。調べて分からなければ「確認できなかった」と書く。
  - 検索語には銘柄名・コードと材料だけを使う。**株数・取得単価・評価額・損益は検索語に入れない。**
- **注文はしない。** 売買の実行・発注・証券会社の操作には関与しない。税金・手数料の具体的な助言はしない（一般的な注意にとどめる）。

## 銘柄ごとに見る項目

1. **損益と構成比** — 評価損益、全体に占める比率。1銘柄が大きすぎないか。
2. **トレンド** — 20日線・60日線との差、高値からの距離、60日の騰落。上昇・横ばい・下落のどれか。
3. **値動きの大きさ** — 日次変動と最悪の1日。「あと-10%になったとき評価額がいくら減るか」を円で書く。
4. **出来高** — 直近平均との比。大きな動きに出来高が伴っているか。
5. **直近の開示** — 題名の事実だけ。本文を読んでいないものは内容を推測で補わない。取得済みの期間に注意（「なし」と「不明」は違う）。
6. **市場・業種との比較** — 同業種・市場全体より強いか弱いか。個別の要因か、地合いの影響か。
7. **（任意）Webで確認** — 直近の決算・業績予想・材料。確認できた事実だけを、出典付きで。

## ポートフォリオ全体で見る項目

- 業種の偏り、上位銘柄への集中。
- 銘柄どうしが同じ要因（例: 半導体市況、金利）で動かないか。
- 全体の値動きの大きさ（最も大きく動く銘柄の影響）。

## 結論のつけ方

銘柄ごとに、次のどれか1つの**状態**を付け、理由を2〜3行で書く。

- **保有を続けて問題が少ない** — 目立つ悪材料がなく、トレンドも極端に悪くない。
- **監視を強める** — 悪化の兆しがあるが、判断を急ぐ材料は足りない。
- **見直しを検討したい** — 下落トレンド、大きな悪材料、構成比の偏りなど、保有を続ける前提を点検すべき事情がある。

あわせて必ず書く。
- **確からしさ**: 低 / 中 / 高（データが少ない・確認できない点が多いなら低にする）。
- **見直しの条件**: 「終値が○○円を下回る」「○○の開示が出る」のように、あとで機械的に確認できる形で2つまで。

## 出力の形（Markdown）

```
# 持ち株の評価（株価日 YYYY-MM-DD）

## まとめ
（全体の損益、いちばん気にすべき点を3行以内。結論の一覧表: 銘柄 / 状態 / 確からしさ）

## 銘柄ごと
### コード 銘柄名 — 状態（確からしさ）
- 事実: …
- 解釈: …
- いま買うとしたら: …
- 見直しの条件: …
- 調べたこと（出典・日付）: …

## 全体のリスク
…

## 限界
この評価に使ったデータと、使えなかったもの。投資助言ではないこと。
```
